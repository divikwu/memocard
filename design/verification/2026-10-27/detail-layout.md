## MemoCard 的实现决策

| Before | After | Why |
| --- | --- | --- |
| 正文段落、列表及列表子段落分别叠加 margin | 详情段落纵向 padding 6px；列表组 padding 6px，条目 padding 2px，内部段落 margin 0 | 同组列表更紧凑，段落拥有完整、稳定的块区域 |
| 标题、属性、正文分别由 8px、2px + 6px、8px 形成基线 | 保留同一 8px 文字基线；不重复增加横向 padding | 避免编辑文档的 DOM 包裹变化，也避免文字额外缩进 |
| 属性区标签 gap 为 6px × 8px；窄屏标签列按 40% 占位 | 标签 gap 4px；属性名称列在 96–160px 内分配；属性容器不超过 28rem 时标签值使用整行 | 保留所有标签，自然换行，减少窄屏的纵向堆积；按组件宽度适配，不依赖特定设备视口 |
| 属性分隔线到正文 32px | 调整到 24px | 将属性与正文清楚分组，同时减少空白 |
| 块选中直接改 background，并清空 pre / th 背景 | 普通块使用非交互伪元素；代码使用 inset 选区绘制；整表选择复用单元格选区层 | 保留代码、表头与提示块底色及横滚提示，选中不改变几何或滚动尺寸，横滚不丢失高亮 |
| 把手定位只读取块外框与行高 | 首行中心计入上下 padding，图片保留既有几何策略 | 保证段落、标题、代码的首行控制位置正确 |
| 共享标签样式静态携带属性编辑器样式 | 共享 tag.css 与按需加载的属性控件样式分离 | 标签 token 与胶囊仍只有一个定义，列表无需提前加载编辑表单 CSS |

布局规则归属 `ui/business/Editor.css`，不修改全局阅读排版 `typeset.css`。保留现有 ProseMirror 节点结构、Markdown 数据及编辑交互；不引入兼容布局或额外真实块 wrapper。
