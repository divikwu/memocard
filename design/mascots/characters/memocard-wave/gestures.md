# MemoCard glasses gesture trial

Made with the built-in image generation tool using the approved runtime front pose as reference. Source: `gestures.raw.png`. `build-gestures.py` registers all poses to the note plate's top edge and width so the moving left arm does not re-center the character. Output: `design/mascots/history/runtime-sheets/memocard-wave-gestures.webp`, with aligned `gesture-greeting.png`, `gesture-adjust.png` and `gesture-relax.png` kept here.

Hover behavior: the existing greeting pose is visible first; at 650ms a front-facing glasses-adjusting pose appears, and at 1500ms the left hand relaxes. Leaving restores the existing pointer-tracking mascot. Pointer down or key down cancels the gesture timers, keeping page-mascot's existing reaction sprites and click behavior available. The sequence is disabled for coarse pointers and reduced-motion preference. Direction and reaction atlases, including the original MemoCard variant, are unchanged.

Validation: live browser checks observed greeting → adjust → relax and pointer-leave reset. Clicking during adjustment restored the original sprite immediately, then blink/heart, blink/sparkle, blink/delighted and fourth-click dizzy all worked without the gesture timers returning. Enter also cancels the gesture and triggers reactions. TypeScript, targeted ESLint and diff checks passed; all gesture frames fit without visible clipping. SHA-256 hashes of all four existing direction/reaction atlases match their pre-change values.
