# 已使用组件维护表

本表是组件清单的唯一来源，按**生产实现模块**登记，不把每个内部函数、组合子元素都当成独立组件。Web 范围从 `apps/ui/src/main.tsx` 的运行时静态 import/export、字面量 lazy import 递归可达，穿过 `.ts` 中转；排除声明级 `import type` / `export type`、`import()` 类型节点、测试、Storybook、预览专用模块或树外历史实现。当前为 **93 个 TSX 模块，包含 ui/ 下的 22 个模块**。这是保守的源码模块依赖图，不等于每个导出在每条产品路径都渲染，也不模拟 bundler 的导出级 tree shaking。生产配置启用 verbatimModuleSyntax，inline `import { type T }` 仍可保留模块副作用，必须追踪其 TSX 后代；inline `export { type T } from` 的模块边也保守保留，虽当前 Vite/Oxc 会移除该纯类型 re-export，不声称它一定执行。

共享业务 core 与外观适配器按实际模块分别登记：core 维护共同的状态、事务或内容渲染，适配器负责注入当前控件/图标及加载样式；提取本身不表示独立状态已新增验收。部分 core 仍直接消费 Base UI、Tiptap 或动态 CSS，不能统称为无界面依赖的纯逻辑。本表的可达计数仍限定上述 `src/main.tsx` 入口；独立 UI-next 入口及其专属组件的迁移范围与验收见 [Web/H5 对齐记录](ui-next-sidebar10.md)，不将其全部计入此入口依赖图。

平台缩写：**Web** 包括浏览器、H5、本机 Web 和 macOS WebView；**Web 内容**也可出现在 iOS WKWebView 内，iOS 导航和系统表面由原生实现拥有。**内部**表示由所属组件统一维护，无需单独 Story。第三方 React、Base UI、编辑器和系统库的内部节点不纳入本表，但本项目的直接适配职责在相应行登记。

Token 族表示**现有消费边界**：Web 基础为运行时语义色、Tailwind 字号/间距/圆角；sidebar 为侧栏生成 token 与现有 CSS；editor 为正文排版偏好、编辑器/代码/标签/Callout 样式；系统度量由 iOS 拥有。列出 token 族不代表已全部迁移到共享 JSON，局部固定值仍需按组件后续审查。

“验证入口”可为组件 Story、关联业务测试或现有整页 fixture。关联入口不是该模块每个分支已执行的证明；“缺口”明确记录未完成的独立故事、状态或设备覆盖。已有 Story 也不代表全状态、真实设备或性能验收。搜索与快速记录以生产组件的 Story 和原生独立 Preview 维护，场景与操作方式见 `design/components/search-capture.md`；状态 fixture 不代替真实 bridge 或设备验收。

`node scripts/check-design-inventory.mjs` 只检查运行时模块登记和引用路径，不把“已登记”升级为“Story/测试全覆盖”。人工仍需审查表中的平台归属、状态、token 和覆盖缺口。当前范围使用字面量动态 import；新增无法静态识别的动态模块入口时，门禁拒绝静默漏报，需先明确新的可达性规则。
