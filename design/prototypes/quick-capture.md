# 主页快速输入 · 原型（归档）

此文档保留旧交互原型的设计讨论；对应运行页面已随旧 Preview 退役。现行状态验收和吉祥物入口见[状态 Preview](../ui-preview.md)。以下布局参数和待反馈事项为当时原型记录，不是当前组件规范。

问题：在现有主页顶部加入 Input Group，保留标签、图片与「记录」后，页面密度和输入体验是否合适。



按当前已选方向提供一版：768px 内容宽度，首页标题下方放多行输入，底部左侧标签/图片，右侧记录。沿用已确认的 Tab 间距。

- Input Group 是官方 Base Nova 源码的原型内副本，只调整导入路径，未覆盖正式组件。
- 标签可多选/移除，图片仅用本地 Blob URL 预览，可移除。
- 记录或 ⌘ / Ctrl + Enter 将内容添加到页面内示例列表，再清空输入；标签本身不能提交空记录。
- 示例列表用首行作为显示标题，仅为展示结果，不决定正式笔记的文件名或标题策略。
- 不连接真实笔记库、不上传文件、不写入 Markdown，刷新或重置恢复示例状态。

待确认：输入框高度、工具栏密度和记录后展示方式。
