# 主页与固定 · 交互原型（归档）

此文档保留旧交互原型的设计讨论；对应运行页面已随旧 Preview 退役。现行状态验收和吉祥物入口见[状态 Preview](../ui-preview.md)。以下布局参数和待反馈事项为当时原型记录，不是当前组件规范。

问题：主页「最近更新 / 已固定」Tab、布局切换，以及详情右上角的大头钉位置是否清晰。



- 只有一版布局，沿用现有 MemoCard 视觉与控件。
- 主页合并为一个内容区，用「最近更新 / 已固定」Tab 切换，默认显示最近更新的列表。
- Tab 右侧切换卡片 / 列表布局，对两个 Tab 都生效；不显示「查看全部」。返回详情来源时保留所选 Tab 和布局。
- 卡片与现有 NoteCollection 保持一致：256px 高、16px 圆角、自适应列数、标题与时间、正文预览、标签控件。列表复用现有紧凑结构，标题、标签、时间同排显示。
- 所有笔记支持卡片与列表切换、搜索与标签筛选；点击笔记进入详情。
- 固定到主页 / 取消固定只在详情右上角操作。
- 所有卡片和列表，包括主页的已固定卡片，均不显示固定或取消固定按钮。
- 文案：固定到主页 / 取消固定；主页区域：已固定。
- 详情的大头钉始终显示。
- 示例日期以 2026-10-14（Asia/Shanghai）为基准。
- 所有内容与固定状态只在内存中，刷新或「重置」恢复初始状态。未连接真实笔记库和服务 API。
- 不属于正式功能；布局确认后再实现持久化、查询及多端行为。

待反馈：主页布局、卡片密度、按钮位置与固定状态辨识度。
