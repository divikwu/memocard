# 新版 UI 与旧版功能交互对照审查

目标是完整审查当前业务组件及 Web/H5，修复有证据的迁移遗漏、交互退化、视觉与可访问性问题，并建立可追溯的验收矩阵。保留已确认的 Luma、8px 默认圆角、Noto 标题/正文字体组合及 Typeset；不另起一套视觉。数据、版本、保存、草稿和撤销契约继续共享。

验收覆盖：

1. 笔记库选择/切换/重授权、导航/标签、筛选、固定、布局、分页与搜索。
2. 快速记录、编辑器、Markdown、属性、图片/图表、撤销、保存失败/冲突、草稿恢复及回收站。
3. 桌面及320/390px窄屏、浅深主题、字体/圆角变化、长内容、键盘/触控、焦点和错误反馈。
4. 初始/后台加载、空态、只读/权限、断线/迟到响应、发布构建样式边界及实际加载成本。

完成标准：范围内有证据的严重/重要问题修复并回归；关键流程在实际浏览器完成；新旧关键测试、类型检查及构建通过；每项结论区分源码审查、自动化验证、浏览器验证与待真机验证。

iOS/Mac原生重新适配后置。本轮不发布、不替换已安装客户端、不向真实笔记库写入。手机软键盘、OS手势、安全区和实际Safari聚焦缩放等硬件相关行为不能以桌面窄屏模拟替代。

## 保留的边界与后续

- 当前Chromium桌面/视口模拟覆盖320、390及桌面；真实Safari软键盘/聚焦缩放、IME硬件组合、安全区和OS原生手势未验收。浏览器工具在原生HTML拖拽中没有成功投递Esc取消，不能称该原生手势已通过；取消逻辑有真实Tiptap回归，实际放置/撤销和提示线有浏览器证据。
- 现有`beautiful-mermaid`版本不支持`graph TD; ...`单行header分号写法，新旧共同保留源码并显示错误。示例改为支持的多行语法；没有用不可靠预处理扩大解析范围。
- 已连接桌面首页依赖图约59个JS文件、gzip估算396,978B，另有既有两张Mascot sprite共1,596,774B；共享App仍保留约58.7KB原生fallback可达JS。它们是明确的剩余加载成本，不是已测得的LCP/网络性能结果。详见构建报告，未为降低数字改写App架构或降低已确认素材质量。
- 本轮未提交、推送、发布、替换原生客户端或向真实笔记库写入。iOS/Mac新视图适配保持后置。
