# MemoCard 性能优化结果 · 2026-10-11

本轮完成排序、文件读取、属性读取和详情加载链路的优化，并加入路由体积预算。千篇合成库的暖单篇读取从约 9.74 秒降至 243 ms，属性读取从 20.36 秒降至 249 ms，正文保存从 9.82 秒降至 260 ms。前期审查中的全部长期目标尚未达标，剩余范围见下文。

基线是 HEAD `ad66615` 加既有的详情刷新骨架屏修复；该修复得到保留。此前只读审查与建议目标见 [性能审查](./PERFORMANCE_REVIEW_2026-10-11.md)。本报告随本轮性能优化一并交付，提交与合并记录以仓库历史为准。

## 已实施的优化

- **日期解析复用**：`ParsedNote` 保存经过验证的 `createdDate`，排序和日期筛选直接使用 Date，保留原有时间顺序和 ID 决胜规则。
- **本地文件缓存命中提前**：每次扫描仍枚举目录并检查路径、文件类型、可用性和冲突；仅本地 APFS 上的非 iCloud 文件，device、inode、size、mode、纳秒级 mtime / ctime 全部一致时，复用已经解析的内容，省去正文读取和 SHA-256。读取前后 stamp 不一致时不保存可命中的 stamp。网络盘、其他文件系统和 iCloud 文件继续协调读取；写入仍协调读取目标并验证 baseHash。
- **属性读取复用**：单篇属性请求从两次全库扫描改为一次；库级选项从已验证快照中的 YAML header 获取并缓存，按需要汇总，不再重读全库正文。选中笔记仍重新协调读取，返回实际源文件的 contentHash。
- **详情关键路径**：识别详情路由后预加载 Editor；宿主与 vault 确认后先请求当前笔记，再启动列表。草稿恢复仍先于可编辑状态，列表、标签、目录和 vault registry 不再共同阻塞详情。保留代际检查、切库隔离及断开时的 registry 错误处理。
- **按模式加载与渲染复用**：native / local-web 不加载浏览器目录存储；浏览器模式在界面挂载前完成 transport 加载，保留目录选择器的同步用户激活。富文本仅在存在保留格式块时加载完整 Markdown 预览。未变化的卡片 props 复用预览，不再重复进入 Markdown 渲染。
- **静态资源缓存**：仅 bundled `assets/` 下带 hash 的 JS、CSS、字体和指定图片扩展使用 `private, max-age=31536000, immutable`。HTML、无 hash 入口、API、授权和笔记附件保留原有 no-store 策略。没有扩大鉴权或网络权限。
- **体积回归预算**：Vite 输出 manifest；检查入口与列表、详情、保留格式详情的静态依赖闭包，避免只检查 index.html。入口 gzip 预算收紧至 180 KiB；其他路由先采用本轮已达到的预算，保留后续收紧空间。

## 原生收益

环境：Apple M4 / 16 GB / macOS 27.0.1，Swift release；临时 Obsidian 兼容库，每篇正文 2,080 UTF-8 字节，没有修改真实笔记。基线每操作一个暖样本；优化后每规模、每操作 30 个暖样本。下表收益按“基线单样本与优化后中位数”计算，不能理解为基线 p95 或跨设备保证。新 store 不等于磁盘冷缓存。

| 1,000 篇操作 | 优化前单样本 | 优化后中位数 | 优化后 p95，n=30 | 耗时下降 |
| --- | ---: | ---: | ---: | ---: |
| 暖 `getStatus` | 9,804 ms | 247 ms | 262 ms | 97.5% |
| 暖 `queryNotes`，复用 status 快照 | 223 ms | 8.01 ms | 8.64 ms | 96.4% |
| 暖 `getNote` | 9,737 ms | 243 ms | 262 ms | 97.5% |
| 暖 `getNoteProperties` | 20,361 ms | 249 ms | 265 ms | 98.8% |
| 暖 `saveNote`，修改同一篇正文 | 9,820 ms | 260 ms | 290 ms | 97.4% |

保存对照独立使用 `git archive HEAD packages/native-core` 的临时副本；每次用上次返回的 baseHash 保存，正文追加序号，不触发改名。测量包含文件扫描、目标 hash 校验、正式原子写入和返回编码，不包含前端 debounce、草稿持久化或网络往返。

| 100 篇操作 | 优化前单样本 | 优化后中位数 | 优化后 p95，n=30 |
| --- | ---: | ---: | ---: |
| 暖 `getStatus` | 651 ms | 25.4 ms | 26.2 ms |
| 暖 `queryNotes` | 24.0 ms | 2.22 ms | 2.72 ms |
| 暖 `getNote` | 654 ms | 25.0 ms | 25.5 ms |
| 暖 `getNoteProperties` | 1,391 ms | 27.8 ms | 29.1 ms |

1,000 篇新 store 的首次 `getStatus` 从 10,397 ms 降至 1,851 ms，单次样本下降约 82.2%；100 篇从 725 ms 降至 195 ms。首次索引尚未重复 30 次，不能据此宣布 p95 ≤ 2 秒达标。

回归计数验证了：未变化的本地 legacy / Obsidian 文件在暖 getNote / getStatus 中没有新增正文读取；属性请求只扫描一次，未变化的库级属性没有重复解析。外部同长度改写并恢复 mtime、原子替换并恢复 mtime，仍能读到新正文与新 hash。

## 页面加载与资源收益

真实页面沿用同一测试库及详情路径。下表记录服务重启前的新 UI 与旧原生进程对照，只表示前端加载变化。随后已按用户要求重启新版服务；完整链路的复测见下一节。

| 同一测试详情 | 优化前 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| Editor 模块开始加载，导航时钟 | 1,380 ms | 207 ms | 提前约 1.17 秒 |
| 实际加载 JS / CSS 响应体 | 2,194,310 B | 1,723,638 B | 减少 21.5% |
| `/assets/` 响应体，含选中字体 | 2,282,658 B | 1,811,986 B | 减少 20.6% |
| 自动化观察到正文可见 | 1,774 ms | 1,518 ms | 单样本约减少 14.4% |

表中前后正文可见时间均包含自动化观察开销，不能作为精确首次可编辑、p95 或 INP。先前安静环境的复测为 1,415 ms，最终构建复测为 1,518 ms，显示观察值有波动；表中采用最终构建样本。另一次与构建重叠的采样不用于延迟对照。请求证据确认 getNote 已先于 queryNotes 发起，浏览器目录模块和完整 Markdown 预览未在该普通详情中加载。

入口 JS / CSS 离线 gzip 从 214,323 B 降至约 179 KB，下降约 16.4%；详情静态依赖闭包约 1.71 MB raw / 524 KB gzip，列表约 1.23 MB / 372 KB，保留格式详情约 2.06 MB / 629 KB。gzip 数值是离线预算，当前 HTTP 仍未启用压缩。路由闭包不含运行时字体、侧栏动态样式、按使用加载的组件或独立 browser-vault 分支，实际导航资源证据另行保存。

使用生产 `LocalWebServer` 启动独立合成单篇 CacheHost，通过正常一次性链接连接浏览器，预热详情后普通刷新：**41 个 `/assets/` 资源的 transferSize 合计为 0 B**，复用的响应体合计 1,811,945 B；哈希资源返回 immutable 策略，API 仍 no-store。该页面只验证缓存命中，不能与真实库的延迟比较。临时 host 已停止，临时标签页已关闭；现有真实测试页保持可用。
