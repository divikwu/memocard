# 页面式块编辑器

新建笔记进入 `#/notes/new`；已保存笔记使用 `#/notes/:id`。新建自动聚焦正文，不需要标题。当前标签仅在创建时作为属性继承，不写入正文。Cmd/Ctrl+Enter 保存并返回；Escape 关闭块菜单，不离开编辑页。

2026-09-30：默认编辑层改为 Tiptap / ProseMirror 所见即所得。标题、列表、强调、引用等在获得光标时仍显示格式；表格单元格直接输入，公式通过带实时 MathML 预览的面板修改。正文复用阅读视图的 Typeset 样式和用户配置。Markdown 仍是主文件，文件接口及保存会话不变。

插入菜单提供正文、H1–H6、三种列表、引用、代码、分割线、表格、行内/块公式及已有图片导入。块手柄支持同容器拖动、上移、下移、复制、删除；列表项携带子列表。文字选区保留，选择文字时可以操作加粗、斜体、删除线和行内代码。列表 Tab/Shift+Tab 调整层级，Cmd/Ctrl+Enter 沿用保存返回。

`MarkdownSource` 记录顶层原始片段及内容指纹：没有改变的块直接复用原文，修改过的块才生成 Markdown，保留文档换行风格；打开不写入，撤销恢复原文。复杂未识别结构、HTML 注释和引用定义保留为不可直接编辑的原格式块，不静默丢弃。修改一个列表内部内容时，目前以整个顶层列表作为生成单位，列表标记可能标准化；不应宣称任意 Markdown 均能逐字往返。

保存采用 650ms 防抖和串行队列；恢复副本与主文件写入按序处理，只有最新内容已写入主文件才显示“已保存到本地库”。新笔记为空不创建文件，已有笔记可以清空。未完成记录通过列表入口恢复，不在加载库时自动提交。冲突暂停自动提交，提供继续编辑、重新加载及同目录另存副本。读取未知笔记地址失败时保留错误提示，不循环请求。

正文默认使用系统字体，标题默认跟随正文，代码使用系统等宽字体栈。正文提供 14px、16px 两档基准字号，行高由内容风格设置决定；正文排版参数仅作用于笔记内容，字体跟随外观设置。已有的字体和排版选择继续保留。

# 拖动交互补充（2026-09-30）

拖动落点以目标块的上／下半区决定前／后插入，不再根据源块位于目标上方还是下方推断。蓝色插入线对齐正文边界，无效层级及原位移动不显示可用落点。拖起时选中源内容并提供内容拖影，原生 dragover 期间接近滚动容器边缘会滚动；结束、取消、卸载时清理拖影。

测试库真实拖动记录 `1650d073-db2d-43ff-be81-db6e49b7654e` 验证了前插、后插和一次撤销。完整 `pnpm verify` 通过（251 UI tests）。边缘滚动与拖影已实现，但自动化工具不能停在拖动中途截取连续状态，连续拖影、触摸和中途 Esc 仍需手工体验；本轮不扩展连续多块及跨容器拖放。
