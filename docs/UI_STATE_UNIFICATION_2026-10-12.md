# 状态提示统一优化

## 优化目标

1. 页面级提示放在内容区顶部、标题上方，覆盖读取、保存、冲突、属性读取及只读说明。
2. 复用描边提示布局：图标、简短标题、必要原因、相邻的恢复按钮。单个按钮使用描边；多个按钮区分主要操作与辅助操作。
3. 收紧顶部留白，详情与列表使用一致的起始间距。窄屏长文本可换行、操作区可折行。
4. 同一错误只展示一次。弹窗、编辑弹层和字段校验保留操作现场的错误，避免背景页面重复提示。
5. 读取失败与真实空库、服务断连分开判定；保留编辑内容、草稿和原有恢复行为。

## 已完成

- 新增复用现有 Alert 的 PageNotice，用于页面错误、编辑器错误、属性读取失败和只读说明。
- 保存、冲突、附件操作错误及待打开链接说明移到笔记标题上方；属性读取失败与只读说明不依赖属性区展开。
- 页面全局提示及草稿提醒移到列表标题上方；保留多种状态各自的原因和操作。
- 详情桌面顶部内边距由 96px 收紧为 32px，窄屏由 40px 收紧为 24px；列表顶部同步收紧。
- 冲突操作相邻排列，另存副本使用描边，重新加载和继续编辑使用辅助按钮。原有确认与保存逻辑保留。
- 属性弹层处理同一保存错误时，背景页面不再重复提示；拒绝有损转换后不提供无效的重试保存操作。
- 读取失败不再显示空库新建引导。服务已响应时，普通查询超时不再误判为断连；真正的服务不可用或授权失效仍使用重连提示。
