# 笔记属性布局

2026-10-10：根据用户提供的 Notion 页面实测，采用共同外框与内容内缩的布局。该结论适用于当前 Markdown 笔记页；自定义 YAML 属性在页面内编辑。

## 两条对齐线

- 外框线：标题容器、属性区和正文容器同宽；分隔线铺满外框。
- 内容线：标题文字、属性图标、展开箭头和正文起点均相对外框内缩 8px。
- 标题左右 padding 为 8px；属性区左右留 2px、属性单元格再留 6px；正文通过编辑器 gutter/inset 各留 8px。
- 属性名文字在 16px 图标后留 4px。图标绘制轮廓可以不同，占用的布局空间保持一致。

Notion 参考页中，标题 padding 为 8px，属性外层左侧 padding 为 2px、名称单元格左右 padding 为 6px；正文通过外层 6px 与编辑区 2px 达成相同的 8px 内容起点。MemoCard 将右侧也统一内缩 8px。

## 属性行

全部属性默认收起，只展示「属性」按钮，不显示数量；展开后依次展示标签、更新时间、创建时间和文件名。属性区不展示所在目录。

| 部分 | 采用的规则 |
| --- | --- |
| 名称列 | `min(160px, 40%)`，桌面采用参考页的 160px，窄屏为值列保留空间 |
| 值列 | `minmax(0, 1fr)`，最小宽度为 0，允许长内容换行 |
| 两列间距 | 8px |
| 单行 | 32px，内容行高 20px，上下各留 6px；名称和值同步使用 |
| 行间距 | 4px |
| 多行值 | 自然增高，名称保持首行垂直居中，值不截断 |
| 展开按钮 | 高 32px，左右 padding 为 6px/8px，图标与文字间距 4px |
| 属性分隔线 | 底部 padding 为 12px |
| 标题到属性 | 8px |
| 分隔线到正文容器 | 32px |

属性行使用语义化 `dl / dt / dd`，两列用 CSS Grid 统一分配。保留项目现有 Base UI Collapsible 管理展开、收起和键盘操作。

展开按钮与可编辑的自定义属性值提供 hover 背景；系统时间、文件名和正文标签汇总保持只读；可编辑字段的名称打开字段菜单。padding 在常态就存在，hover 与 focus 不改变宽度、间距或文字位置。

正文随内容自然增高，最小高度为一行（`1lh`）。底部 `4rem` 写作留白放在编辑器外层，不计入可编辑正文高度；点击正文下方留白进入文末空段落，已有顶层空段落时直接复用，否则只追加一个，可单步撤销。列表、代码块等结构之后追加普通段落，不进入原块内部。只读、输入法组合输入及交互控件点击不触发追加。页面段落间距规则仅作用于外层 `section.note-editor`，避免影响编辑器内部控件。

## 验收

桌面、390px 和 320px 视口分别检查共同的 8px 内容起点、16px 图标、列宽、长文件名换行和横向溢出。展开、收起及 hover 前后比较按钮几何尺寸，并确认查看属性没有改写笔记。

## 依据

- 用户提供的 Notion 页面 DOM、计算样式及分隔线实测；具体尺寸为该页面当前状态，不视为 Notion 的全产品规范。
- [W3C CSS Grid](https://www.w3.org/TR/css-grid-1/)：明确网格轨道的最小值，避免长内容撑宽值列。
- [W3C Reflow](https://www.w3.org/WAI/WCAG21/Understanding/reflow)：以 320 CSS px 下无信息丢失、无需横向滚动作为窄屏检查目标。

## 自定义 YAML 属性

全部属性仍默认收起。系统信息之后显示已有 YAML 自定义字段，并提供添加属性。第一版支持文本、字符串列表、日期（YYYY-MM-DD）和复选框；点击属性名打开字段菜单，删除入口收在菜单内并保留确认；文本值在原值列内直接替换为输入框，保持相同宽度、字体、行高和 6px 内边距，输入随内容自动增高；不另显示保存、取消按钮。列表和日期值仍使用各自的编辑弹层。列表显示为多个标签，复选框直接切换。文本 Enter 保存、Shift+Enter 换行；列表 Ctrl/⌘+Enter 保存。点击外部保存当前值，Esc 或取消丢弃本次输入；保存失败保留输入与错误提示。组合输入时 Enter 不触发保存。字段类型通常由 YAML 值推断；空日期写为 `null # memocard:type=date`，通过标准 YAML 行内注释保留日期类型，普通 null 不作日期处理。填写日期后写回 YYYY-MM-DD；再次清空时恢复类型注释。数字、嵌套对象、块标量等暂时只读；含锚点、别名、显式标签或顶层 flow mapping 的 YAML 整体只读。

`getNoteProperties` 按当前源文件读取；`updateNoteProperty` 在正文保存队列完成后，按当前 contentHash 更新指定字段。仅更新目标字段及旧格式笔记的系统 updatedAt，不重建未知字段，保留其他 YAML 内容、BOM、换行与正文。属性标签通过专用弹层编辑 YAML `tags`，搜索、创建、选择与移除后自动保存；页面将两种来源合并为一行「标签」，同名去重；编辑弹窗内保留来源提示，正文标签点击定位原文，不能通过属性操作移除。侧栏与筛选合并去重两种来源。保留字段 id、createdAt、updatedAt、deletedAt 不可通过属性表单修改；不兼容的 YAML 标签值只读并保留。文件被外部修改时拒绝覆盖并保留表单输入。

新笔记先填写标题或正文并保存，再添加属性；读取和展开属性不会创建文件。新增属性只需输入名称并选择类型，选择后立即创建空属性并关闭弹窗；文本、日期的界面值为空字符串，列表为空数组，复选框默认未勾选。名称为空时不能创建，失败保留名称和类型列表；文本值使用 Enter 或移出焦点保存；其他现有值支持保存按钮、快捷键或点击外部保存，未修改的值不会写入。取消不写入文件。新增类型菜单宽度为 min(280px, 视口宽度 - 24px)，已有值的编辑弹层宽度为 min(360px, 视口宽度 - 24px)，由 Base UI 处理碰撞与焦点；各尺寸仍共用既有属性网格和 6px 内边距。


### 日期编辑弹窗

现有 YYYY-MM-DD 日期字段采用单层弹窗：顶部直接输入日期，中间为中文单选月历，提供上/下月、相邻月份日期和「今天」。选中日期立即保存，手输 Enter 或点击外部保存，Esc 取消；保留写入冲突时的输入。无效日期（如 2026-02-30）不会写入。新增日期属性不要求初始值；已有日期允许清空并保存，刷新后仍保持日期类型。

月历使用 React DayPicker 9.14 的单选、方向键和焦点管理，外层继续使用已有 Base UI Popover；不叠加浏览器系统日期弹窗。日历按本地年月日读取和序列化，不经过 UTC 日期截取。弹窗沿用视口碰撞处理，宽度 min(280px, 视口宽度 - 24px)，颜色和选中态使用项目现有主题。

### 标签选择弹窗

参考 Notion 多选属性，已选标签和搜索输入位于顶部浅灰区域，输入跟随标签排列；分隔线下、候选列表上方仅显示「选择或创建」静态说明，标签右侧 × 移除当前笔记中的属性关联。候选项支持搜索和滚动；不再限制前 12 项。搜索允许带 #，以 NFC 和不区分大小写进行匹配；同名候选存在时不提供重复新建，标签身份统一为小写与 NFC；正文中新输入、粘贴或修改的有效标签同样转换为小写，代码、链接和 Markdown 标题不转换。打开旧笔记不自动改写已有标签，大小写转换并入当前编辑的撤销步骤，组合输入结束后再转换；属性与正文同名标签、计数与筛选按同一身份处理。合法且不存在的名称显示「新建 #名称」，选择后立即保存到 YAML tags。

弹窗中的多选、方向键、高亮、Enter 与空输入 Backspace 移除末项由 Base UI Combobox 管理，外层仍使用 Popover，不增加第二层弹窗。选择成功清空搜索词；移除保留搜索词。保存期间保持输入焦点并阻止重复写入；失败保留原有选择、搜索词和错误。候选加载完成前不开放新建；读取失败仍可移除已有属性标签，重新打开弹窗可重试。正文标签及其他笔记不受移除影响。

页面的「标签」值合并属性与正文来源并去重。弹窗内，属性标签保留可移除芯片；双来源芯片的标签文字可点击定位原文，× 只移除属性关联，移除后该标签仍作为正文来源显示。顶部「已选标签」统一展示全部来源，同名去重，搜索不隐藏已选标签。仅来自正文的标签不额外标记来源，不提供 ×，也不能使用 Backspace 删除；hover 或键盘聚焦显示「正文标签，点击定位」，点击标签文字定位原文。双来源标签的来源与移除范围同样通过提示说明。点击定位会关闭弹窗，由编辑器接管焦点与选区；Esc 等普通关闭继续恢复触发按钮焦点。来源标签不参与属性多选的芯片索引，避免空输入 Backspace 误删正文来源。

标签弹窗的最大高度使用 Base UI 计算的 `--available-height`，内容超出时在弹窗内滚动；仅作用于标签弹窗，各断点共用，不固定到验收视口尺寸。

正文、属性行、已选标签和候选标签共用同一标签外观：默认浅灰底、深灰文字、全圆角、14px 字号、20px 行高与左右 6px 内边距。属性标签保留 ×，正文标签的提示与定位行为不变；普通自定义列表值不套用标签样式。

标签弹窗保留两行已选及输入区域、候选列表顶部的静态说明，移除重复标题和常驻保存说明。候选始终隐藏已选属性标签和当前正文标签，搜索同名标签后按 Enter 不移除已有属性关联；当前笔记正文中的标签始终从候选中排除，只在上方显示并支持定位，搜索同名标签也不重复创建。其他笔记使用的标签仍可选择。× 的提示说明仅移除属性关联。仅保存中、读取失败或写入失败时显示对应状态。

顶部已选区采用浅灰背景和底部分隔线，下方静态说明与候选列表使用页面背景，不重复添加内层边框。搜索输入紧跟已选标签，静态说明和候选列表随后排列，各断点共用同一布局。已选区域最小高度为 48px（两行 20px 标签加 8px 行间距），横向间距保持 4px，超过两行自然增高；搜索输入与标签共用该区域，空白处点击聚焦输入。继续使用 Base UI Combobox 管理输入与芯片键盘行为。

候选列表尚可向下滚动时，底部显示 24px 渐变遮罩，与弹窗背景同色（浅色为白色，深色跟随主题）；遮罩不拦截点击，滚到末尾或列表无需滚动时隐藏。

标签来源和移除范围统一使用公共 Base UI Tooltip，包含属性行、已选属性标签与 × 按钮；移除原生 title 提示，避免出现两套外观或重复提示。来源提示仅绑定标签文字，× 独立触发移除说明，避免嵌套提示覆盖键盘聚焦的按钮说明。标签选择、正文定位与键盘删除行为不变。

标签提示使用来源与操作相结合的简短文案：属性标签「属性标签，可移除」，正文标签「正文标签，点击定位」，双来源标签「属性和正文均有，点击定位」，× 按钮「移除属性标签，保留正文标签」；不能定位时提示在正文中编辑。页面属性行只说明来源，不提示定位，因为点击属性行会打开标签编辑弹窗。

已选标签及候选项右侧「…」仅提供颜色设置，不提供删除或重命名标签。默认使用灰色，可选棕、橙、黄、绿、蓝、紫、粉、红；颜色按当前浏览器与笔记库保存，刷新保留，不写入 Markdown 或 YAML。旧颜色、置顶和图标设置按小写标签名兼容读取；颜色设置冲突时优先已有小写名称。已有 `gray` 设置读取时按默认处理，下次保存该笔记库颜色时清理旧值，其他颜色与笔记库不受影响。属性行、已选标签、候选项、正文与笔记列表中同名标签同步使用颜色，并适配深色模式；重命名标签时迁移其及子标签的颜色。× 仍只移除当前笔记的属性关联。菜单支持键盘与窄屏碰撞避让，触屏常显「…」。

颜色统一由 `tag-colors.css` 的底色与前景色配对提供。× 及色块中的标签图标跟随标签前景色，悬停保留色相；颜色菜单标题显示实际标签样式，右侧勾使用对应颜色。侧栏标签（含置顶与嵌套标签）的名称、图标、选中与悬停底色使用统一导航样式，不受标签自定义颜色影响；Emoji 保留原有颜色。正文、属性与候选标签保留自定义颜色，颜色样式由常驻标签导航异步加载，并随笔记库切换更新。

所有标签（含默认灰色、彩色及菜单色块）以对应前景色生成半透明底色：浅色模式 8%，深色模式 16%，共用 `--tag-bg-opacity`。文字与图标保持原有实色，不对整个标签设置 opacity。不同标签可保持各自颜色，不修改已有颜色设置；透明底会随容器背景略有变化。

黄色使用金黄色相，与偏红的橙色区分：浅色采用 yellow-700 混入 8% 黑色以保持小字号文字对比度，深色采用 yellow-200，底色透明度规则不变。

已选标签区域不显示颜色设置「…」，只保留移除与正文定位；候选行继续提供颜色设置。「…」是中性操作按钮：常态灰色图标，悬停、键盘聚焦或展开时使用主题中性灰底与前景色，不跟随标签颜色。默认颜色引用灰色配对，不修改已保存的自定义颜色。

### 选择与多选属性

新增「选择」「多选」类型；原有字符串列表显示为「文本列表」，不自动转换。名称加类型即可创建空属性。选择值只保留一个选项，多选可增减多个值；搜索、新建、方向键、Enter 与芯片移除使用 Base UI Combobox，已选值通过顶部芯片展示，候选列表不显示选中勾。单选保存后关闭，多选保持打开；空值也保留类型。选项名称可包含空格并保留大小写，不沿用标签的小写规范。

选择、多选与标签共用已选区域、输入框、候选行及 `PropertyOptionList` 滚动列表和底部渐变。属性行、已选区域和候选中的选项均复用全圆角标签样式，字号、内边距、行高和间距一致。选项通过行尾中性「…」设置颜色，颜色复用现有标签调色板（浅色 8%、深色 16%），但选项不加入标签索引，也不改变标签颜色。同一笔记库中，同一 YAML 键共用类型、选项名称及颜色，各篇笔记只独立保存选中值。移除已选值保留库级选项，之后可重新选择；选项改名会同步替换全部笔记中的对应值，删除选项会移除全部笔记中的对应选择，改色不会改变选中值。

Markdown 中值仍为标准字符串或字符串数组，类型及选项定义记录在同一行的 `# memocard:choice={"type":"select","options":[{"name":"设计","color":"blue"}]}` 标准 YAML 注释中；多选 type 为 multiSelect。浏览器与原生服务均读取、校验和保存此注释，旧格式笔记的正文保存与重命名也保留它。损坏元数据只读，防止静默丢失；重复选项、未知选中值与无效颜色不写入。保存沿用 contentHash 冲突保护，失败保留输入和选中值。

### 属性名管理菜单（2026-10-11）

参考用户提供的 Notion 属性名菜单截图，将名称管理与属性值编辑分开。自定义字段名称打开宽度 min(220px, 视口宽度 - 24px) 的菜单；32px 菜单行、16px 图标、14px 文字，沿用公共 hover 变量（浅色 6%、深色 16%）与 4px 操作圆角，菜单展开时名称按钮保留底色。重命名和类型切换为一组；创建属性副本、删除属性为一组，删除入口与确认按钮均使用中性色。属性值通过点击右侧值直接编辑，菜单不重复提供「编辑值」入口；复选框继续直接切换。系统字段值仍只读，名称可修改。

重命名打开名称输入，自动聚焦并选择现有名称；Enter 保存、Esc/取消关闭，组合输入不提交，空名不能保存，未改名不写入。标签、更新时间、创建时间、文件名及自定义字段的显示名称均按整个笔记库统一，保存到 `.memocard/property-labels.json`；内置字段用固定系统标识，自定义字段用 YAML 键标识，同库同键共享名称，每篇笔记的值独立。名称修改不改写 Markdown 键、值、选项、时间或文件路径；跨库隔离，浏览器与原生服务使用相同配置格式，刷新、重开和同步后仍生效。内置字段名称菜单只提供重命名，不提供类型切换或删除。配置采用 contentHash 冲突检查与原子写入，拒绝空名、过长名称、控制字符和库内重名；配置损坏时拒绝覆盖，失败保留输入和错误，可刷新配置后重试。

副本使用「名称 副本」，遇到重名递增后缀；复制类型、值及选择选项和颜色，只作用于当前笔记。评论、数据库可见性和自定义布局尚无对应能力，不显示占位菜单项。

### 属性类型切换

属性名菜单提供「类型」子菜单，沿用新增属性的六种类型和图标；父菜单的当前类型文字靠右并紧邻箭头，子菜单的当前类型使用右侧勾选标记，左侧只显示类型图标；鼠标 hover、键盘高亮和聚焦均使用全局 hover 中性色变量。选择当前类型不写入；选择其他类型后直接保存并关闭菜单，不弹出切换提示。转换规则：文本与列表保留内容，选择与多选互切保留全部选项定义和颜色；新生成的选项采用默认中性色。多值转单选只保留首个选中值，其余有效值保留为可选项。转为日期只接受单个有效 YYYY-MM-DD；转为复选框识别布尔值及文本 true/false。不兼容的日期值清空，不能识别的复选框值设为未勾选；转为非选择类型时移除选项定义与颜色。写入失败保留原属性并显示错误，可重新选择类型重试。

日期转文本时写入 `# memocard:type=text` 标准 YAML 注释，浏览器与原生服务均识别；刷新、重开以及保存正文后仍为文本。切换通过 updateNoteProperty 更新库级定义，并逐篇转换所有包含同一 YAML 键的非删除笔记；不改变字段名称、其他属性或正文，未包含该属性的笔记不自动新增。系统元数据类型固定，不支持编辑的复杂 YAML 不提供切换入口。

### 库级属性类型与选项（2026-10-11）

`.memocard/property-definitions.json` 按原始 YAML 键保存类型与选项；显示名称仍由 `property-labels.json` 管理。浏览器与原生服务读写相同格式，重启和重开笔记库后保留，跨库隔离。首次编辑选项或切换类型时，合并同名属性在现有笔记中的全部选项，保留颜色；同名选项的已有颜色不一致时，按文件路径顺序采用首项颜色。选项最多 200 个，超出时拒绝整个修改，避免截断已有值。

类型切换逐篇转换各自的值，不把当前笔记的值复制到其他笔记。选项新增、改名、删除和改色同步写入所有使用该属性的笔记，包括 YAML 类型/选项注释，保证 Markdown 文件单独打开时也保留定义。新建同键属性必须使用已有库级类型，空选项列表自动继承库级选项；普通值修改、移除属性和创建副本仍只作用于当前笔记。

修改使用笔记 contentHash 与定义 definitionHash 双重冲突检查，并复用持久化批量写入日志。完整扫描并验证全部受影响的文件后再写入；只读复杂属性、配置损坏、外部修改或写入失败时拒绝提交或恢复整批。进程中断后自动恢复笔记及定义文件；遇到外部修改保留日志并停止恢复，避免覆盖外部内容。文件的 BOM、CRLF、无关 YAML 与正文保持不变；旧格式仍更新系统 updatedAt。
