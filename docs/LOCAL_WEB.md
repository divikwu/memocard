# 本机 Web

本机 Web 是 MemoCard Swift 文件核心的浏览器界面，由独立菜单栏服务或 Mac App 在随机 loopback 端口提供。菜单栏服务是 Safari、Codex、Chrome 和 Edge 的推荐入口；Mac App 宿主作为兼容入口保留。两者复用 React 界面和文件核心，不需要 Node 写入服务，也不扩大 MCP 的只读权限。

## 使用

1. 构建并安装菜单栏服务：`pnpm build:service && pnpm install:service`。
2. 运行 `memocard serve`，或从菜单栏选择“打开 Web”。
3. 首次使用时从网页、菜单栏打开或创建笔记库；服务通过系统目录选择器取得授权。
4. 在浏览器中查看、新建、编辑、搜索笔记，添加标签和图片，保存或恢复该宿主的本机草稿。

需要在 Codex 内置浏览器或另一个浏览器中使用时，从菜单栏选择“复制访问链接”，在 2 分钟内粘贴到目标浏览器。链接只能兑换一次，重新复制会撤销尚未使用的旧链接；已建立的会话继续有效。

另有 [独立 Web](BROWSER_VAULT.md)：受支持的 Chrome / Edge 页面可通过 File System Access API 直接授权文件夹，不依赖本机服务。本文只描述 Swift 宿主提供的鉴权本机 Web；其页面和资源由宿主提供，不需要 Vite 或另一个服务器进程。

该地址只适用于这台 Mac，不是局域网、互联网或独立 iPhone Web 客户端。iPhone 继续使用原生客户端。iCloud Drive 同步仍由系统负责；浏览器保存成功仅表示本机文件提交成功。

## 权限与接口

- 服务只监听 `127.0.0.1`，校验精确 Host 和写请求 Origin，不允许 CORS。
- 启动链接在 URL fragment 中携带一次性、短时授权；前端立即移除 fragment 中的凭据，通过同源 POST 换取 HttpOnly、SameSite=Strict 会话 Cookie。不要分享启动链接。令牌不写日志、笔记库或仓库。
- 网页直接加载打包的 HTML/CSS/JavaScript/字体；HTTP 页面应用独立 CSP，只允许同源数据与图片，禁止原始 Markdown HTML 执行、嵌套页面和表单提交。
- `POST /api/bridge` 复用版本 1 的结构化请求与响应，仅放行状态、笔记查询/读取、标签、草稿、保存和附件导入。图片通过浏览器文件选择器选择，再传给 Swift 导入。
- `GET /api/assets/assets/...` 需要会话授权，只提供受支持的图片；Swift 再次核对路径、授权和文件可用性，不提供任意文件读取接口。
- 菜单栏服务允许网页请求打开、创建和切换笔记库；服务在主线程显示原生目录选择器，网页不能传入任意文件路径。Mac App 宿主继续在原生界面中管理目录授权。MCP 配置只由 Mac App 管理。
- 切换笔记库、关闭 Web 或退出应用时，监听和会话被撤销。请求绑定启动时的笔记库和授权代次，旧页面不能向新选择的笔记库写入。

## 保存与断开

正文仍使用原始 Markdown，并带读取时的 `baseHash` 保存。Mac、外部编辑器和浏览器并行修改时，Swift 拒绝过期覆盖，保留草稿并报告冲突。

网页可见时定时刷新；返回页面和手动刷新也会重新核对。用户加载更多笔记后，后台检查连接和库状态，避免自动把列表重置到第一页；查看最新列表可手动刷新。

连接断开时不能新建笔记；当前编辑内容保留在页面内，保存失败不会关闭编辑器或清空输入。尚未成功保存到 Swift 草稿的输入，在离开页面前使用浏览器标准提示保护。**这不保证浏览器崩溃或强制退出后恢复未提交输入**。宿主重启通常使用新的端口和授权，旧页面的“重试”无法发现新地址；页面改为提供“重新打开本机 Web”，通过 `memocard-service://open-web` 请求菜单栏服务生成新会话。旧页未保存内容应先复制出来。

网页外观保存在浏览器当前 origin，与原生 WKWebView 独立；动态端口变化后可能回到默认主题。该限制不影响已提交的 Markdown、图片和 Swift 草稿。

## 验证

自动化入口：`pnpm test:local-web`、`pnpm --filter @memocard/ui test`、`pnpm verify`。

菜单栏服务的构建、安全边界和跨浏览器验收要求见 [本地跨浏览器服务](LOCAL_SERVICE.md)。关闭/重启、会话轮换与拒绝越权请求由真实 Network.framework 自动化测试覆盖；断开时保留编辑内容与重新打开入口由界面测试覆盖。本机 Web 验收不替代真实 iPhone 安装、iCloud 双端同步及完整 M0–M5 交付。
