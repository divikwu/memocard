# 内容块菜单优化验收

日期：2026-10-08。范围：参考用户提供的 Codex 空间菜单截图，优化 MemoCard 内容块操作弹窗。

## 实现

- 菜单改为紧凑圆角面板、图标行、操作分组与红色删除，使用现有主题变量适配浅色和深色。
- “转换为”独立子菜单，显示文本、标题 1–6、列表、待办、引用及代码，并勾选当前类型。选择当前类型直接关闭菜单，避免反向切换。
- 新增“在下方插入”，接入现有插入菜单。保留复制块、上下移动、块属性及撤销能力。
- 使用 Radix Menu 提供方向键、子菜单和关闭行为；拖动手柄使用 Menu Anchor，保留原生拖动入口。
- 桌面并排展开；窄屏复用现有移动端判断，子菜单覆盖展开，避免两列宽度超过视口。
- 多块选区及章节操作显示实际作用范围。列表容器和多块选区仍禁用类型转换。

没有添加截图中的复制块链接或编辑者归属信息：当前数据模型不提供可靠的块链接与编辑者记录。本次保留 Markdown 持久化方式。
