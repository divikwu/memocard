# 与 Obsidian 共用笔记库

2026-09-29：基础文件兼容已实现。直接选择 Obsidian vault 文件夹，无需复制笔记或导入转换。新建库使用同一普通 Markdown 方案；现有 formatVersion 1 MemoCard 库继续使用原规则，不自动迁移。

## 文件与保存规则

- 自定义文本列表统一为「多选」编辑，不再提供独立「文本列表」类型。普通 YAML 字符串列表和旧 `list` 类型配置均可读取；打开时不改写文件，编辑保留原值（含空值、重复值和空格）。推断的菜单选项最多展示 200 个，超出部分及从 Obsidian 新增的值仍保留在已选值中，不因选项颜色等定义修改而丢失。保存仍使用 YAML 列表，多选选项与颜色使用 MemoCard 配置/注释记录，不改变 Obsidian 的列表数据格式。
- 打开已有库、新建空库时，只新增 `.memocard/vault.json`（formatVersion 2、vaultId）。不修改 `.obsidian` 配置，不给既有笔记注入 UUID、日期或其他属性。
- 从库根递归发现 `.md`，跳过隐藏目录；保留原文件名和目录。页面标题表示实际文件名（不含 `.md`），与正文 H1、YAML `title` 相互独立。新笔记使用手动输入的标题，未填写时使用“新内容”，正文不生成标题或文件名；仅在同目录重名时追加 ` (2)` 等序号，兼顾 Unicode、大小写和可移植字符限制。默认“新内容”及带编号的文件名不回填到标题输入框，输入框显示灰色“新内容”占位。手动修改页面标题会重命名文件并保持内部 UUID。附件新增到 `assets/`，已有图片可以位于任意非隐藏目录。
- YAML 可有可无。自定义 `id`、`createdAt`、`updatedAt`、`deletedAt` 作为普通属性，不解释成 MemoCard 的身份或删除状态。
- 仅改正文时，YAML 前缀、注释、属性顺序和换行原样保留；不自动修改日期或标签属性。
- 属性区用一行「标签」合并去重展示，编辑弹窗区分来源：属性标签存于 YAML `tags`，可在标题下的属性区搜索、新建、选择和移除；正文标签从 `#标签/子标签` 提取，在正文中编辑，属性区点击可定位原文。侧栏、计数和筛选合并去重两种来源；移除属性标签不改写正文，同名正文标签仍保留。代码、链接等排除规则不变。标签默认显示，其余属性默认收起，更新时间、创建时间和文件名只读，自定义 YAML 字段按受支持类型编辑；新建未保存笔记不虚构文件信息。不兼容的 YAML 标签值保留原文并只读，不批量迁移源文件。
- 本机身份映射：Swift 在独立 localDataURL 保存 JSON，浏览器在该站点 IndexedDB 保存。按原路径保留身份；唯一的内容指纹可识别未同时改正文的外部移动。相同内容有多个候选，或移动同时改正文时，不猜测身份：旧草稿可能提示原文不存在，需要重新打开当前文件。
- 身份映射为设备本地状态，不保证跨设备/原生与浏览器之间的 `memocard://` 笔记 ID 一致。清除本机状态会生成新 ID；文件本身不受影响。时间线初始时间取文件修改时间，本机映射保留创建顺序，不写入原文。

自定义属性支持单张图片：创建「图片」属性后上传，在属性行查看缩略图，点击打开大图卡片，可全屏预览、替换或移除引用。全屏使用基于现有 shadcn / Base UI Dialog 的通用 `ImageViewer`，自适应显示图片，不显示标题，复用通用 Dialog 的默认遮罩，支持点击图片外空白处、关闭按钮和 Esc 关闭；按需加载，图片仍通过原有本地附件读取链路解析，无新增第三方依赖。文件复用 `assets/` 附件存储，YAML 保存相对路径及 `# memocard:type=image` 类型注释；清空后仍保留图片类型。移除引用不删除附件文件。格式和大小限制沿用正文图片，暂不支持远程图片。

自定义数字属性支持正负整数、小数和空值。非空值以 YAML 数字保存，并通过 `# memocard:type=number` 保留类型；桥接传输保留数字原文，避免大整数和高精度小数在保存正文时被舍入。日期属性默认只含年月日，开启「包含时间」后保存带时区的 ISO 日期时间；已有秒、毫秒和时区在仅修改日期时保留，关闭时间后保存纯日期。空数字、空日期分别用带类型注释的 `null` 保留类型。界面复用现有组件及原生时间输入，无新增第三方依赖。

## 标注（Callout）

插入菜单或 `/callout` 可新增标注；区块菜单「转换为 → 标注」可包装现有内容，「普通区块」可移除标注外层，保留段落、列表、链接及行内格式。点击标注图标可直接编辑 emoji，与标签共用图标选择面板；区块菜单「颜色」设置文字颜色和背景颜色（默认及九种预设色）。选择图标或颜色后即保存，清除可移除图标，关闭面板不修改内容；编辑和转换支持撤销。

内容沿用 HTML `aside` 保存，颜色、文字色和图标分别记录为 `data-callout`、`data-callout-text-color`、`data-callout-icon`，不会写入界面控件。原有导入标注仍可读取；MemoCard 在编辑器和阅读渲染中使用同一配色，深色模式自动适配。

## Mermaid 图表

每个 Mermaid 块提供「仅源码」「仅图形」「源码与图形」切换，默认同时显示。右上角复用图标 Tabs，鼠标悬浮或键盘聚焦时显示，触屏始终显示；可使用方向键切换。显示模式仅保留在当前界面，不写入 Markdown，重新打开或刷新后恢复默认；隐藏源码不会删除内容，切回后可继续编辑。

`mermaid` 围栏代码块保留原始源码，并在编辑器和阅读预览中生成图形。按需加载 Beautiful Mermaid 1.1.3，在本地渲染流程图、状态图、时序图、类图、ER 图和 XY 图表；不依赖远程服务或字体。源码修改后更新预览，点击可通过通用 Dialog 放大，支持 Esc、关闭按钮及空白处关闭。无法渲染的语法或图表类型显示提示，源码仍可编辑、保存；预览 SVG 不写入 Markdown。

## 链接与图片

支持 `[[笔记]]`、`[[目录/笔记|显示名称]]`、标准 Markdown 笔记内链、`![[图片.png]]` 和标准 Markdown 本地图片。优先匹配明确路径，Wikilink 再查唯一的短名称，重名时提示使用完整路径。链接复用原来的编辑会话保护，已有编辑内容不会被静默替换。

标题/块片段目前打开对应笔记，不定位具体段落。同页 `[[#标题]]`、正文嵌入、反向链接面板、属性 `aliases` 的名称检索、Canvas、Dataview、插件、PDF/音视频内嵌不在本次实现范围；相关原文保留。图片显示仍限现有 PNG/JPEG/GIF/WebP/HEIC/HEIF，浏览器对 HEIC 的显示取决于浏览器支持，导入仍会明确拒绝不支持的格式。远程图片、HTML 执行、库外路径和隐藏配置读取保持禁止。

编辑器中使用 ⌘/Ctrl + 单击打开链接；列表预览可直接单击。Markdown 图片采用相对路径；无相对路径前缀的引用和 Wikilink 由库内解析器定位。

## 同步与并发

同步继续由外部文件同步服务负责，本次未实现或接入 Obsidian Sync。Mac/iPhone 共用 iCloud Drive 仍需独立授权和双端真机验收。

保存前检查源文件 hash，外部内容变化拒绝覆盖；不完整扫描时保留草稿。Swift 使用系统文件协调，浏览器使用暂存写流并在 close 前再次校验。浏览器不能与外部程序进行系统级原子比较交换，最后检查与提交之间仍有竞态窗口，因此本次不宣称能可靠合并同时编辑。

## 多级标签导航

侧栏按标签而非物理目录组织内容。`工作/项目/设计` 自动生成“工作 → 项目 → 设计”，支持逐级展开和收起；父标签筛选包含所有后代。计数按笔记去重：一篇笔记同时有多个子标签，父级只计一次。父级只作为索引分类生成，不写回原文。实际目录和附件路径保留，继续兼容 Obsidian；编辑现有笔记仍保存到原路径，新建笔记沿用库的默认保存位置，并继承当前选中的标签。

## 标题重命名与旧文件迁移（2026-10-10）

- 原生与浏览器保存均检查原文件 hash；跨文件重命名更新可唯一解析的 Wiki/Markdown 内部链接，保留锚点、显示文字、YAML 和代码字面量。模糊目标与外部 URL 不改写。
- 原生重命名的操作前镜像与恢复记录保存在设备本地 `renames/`；浏览器模式保存在当前源 IndexedDB。未完成事务会先恢复；检测到外部修改时停止恢复并保留证据，避免覆盖用户编辑。文件系统不提供对外部编辑器的全局事务锁，仍应避免同时编辑同一组文件。仅大小写或 Unicode 规范形式变化而目标已由系统视为同一文件时，安全拒绝，不覆盖。
- 旧 formatVersion 1 笔记库继续使用 YAML `id` 保持身份；不修改格式版本。`node scripts/migrate-uuid-notes.mjs VAULT` 只预览 UUID 文件改名；加 `--apply BACKUP_DIRECTORY` 才执行。迁移保留完整库备份和含前后 hash 的 `manifest.json`，先写新文件及引用，再移除旧路径。脚本拒绝 `diw_os`、非 v1 库及符号链接。
- 若恢复迁移，先停止写入并核对 manifest：仅在当前新路径 hash 仍等于 `afterHash` 时恢复备份中的旧文件并移除对应新路径；有后续编辑时先另存差异，不直接覆盖。备份位于库外，不参与云端笔记索引。
