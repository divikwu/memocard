# 与 Obsidian 共用笔记库

2026-09-29：基础文件兼容已实现。直接选择 Obsidian vault 文件夹，无需复制笔记或导入转换。新建库使用同一普通 Markdown 方案；现有 formatVersion 1 MemoCard 库继续使用原规则，不自动迁移。

## 文件与保存规则

- 打开已有库、新建空库时，只新增 `.memocard/vault.json`（formatVersion 2、vaultId）。不修改 `.obsidian` 配置，不给既有笔记注入 UUID、日期或其他属性。
- 从库根递归发现 `.md`，跳过隐藏目录；保留原文件名和目录。新笔记以正文首个非空行加短标识命名，没有正文时使用“未命名”。附件新增到 `assets/`，已有图片可以位于任意非隐藏目录。
- YAML 可有可无。自定义 `id`、`createdAt`、`updatedAt`、`deletedAt` 作为普通属性，不解释成 MemoCard 的身份或删除状态。
- 仅改正文时，YAML 前缀、注释、属性顺序和换行原样保留；不自动修改日期或标签属性。
- 标签只从正文 `#标签/子标签` 提取，去重并排除常见围栏代码、行内代码和链接；不执行插件。标签直接在正文中编辑，不提供独立属性区。既有 YAML `tags` 不再参与索引，不迁移成正文，也不批量改写源文件。
- 本机身份映射：Swift 在独立 localDataURL 保存 JSON，浏览器在该站点 IndexedDB 保存。按原路径保留身份；唯一的内容指纹可识别未同时改正文的外部移动。相同内容有多个候选，或移动同时改正文时，不猜测身份：旧草稿可能提示原文不存在，需要重新打开当前文件。
- 身份映射为设备本地状态，不保证跨设备/原生与浏览器之间的 `memocard://` 笔记 ID 一致。清除本机状态会生成新 ID；文件本身不受影响。时间线初始时间取文件修改时间，本机映射保留创建顺序，不写入原文。

## 链接与图片

支持 `[[笔记]]`、`[[目录/笔记|显示名称]]`、标准 Markdown 笔记内链、`![[图片.png]]` 和标准 Markdown 本地图片。优先匹配明确路径，Wikilink 再查唯一的短名称，重名时提示使用完整路径。链接复用原来的编辑会话保护，已有编辑内容不会被静默替换。

标题/块片段目前打开对应笔记，不定位具体段落。同页 `[[#标题]]`、正文嵌入、反向链接面板、属性 `aliases` 的名称检索、Canvas、Dataview、插件、PDF/音视频内嵌不在本次实现范围；相关原文保留。图片显示仍限现有 PNG/JPEG/GIF/WebP/HEIC/HEIF，浏览器对 HEIC 的显示取决于浏览器支持，导入仍会明确拒绝不支持的格式。远程图片、HTML 执行、库外路径和隐藏配置读取保持禁止。

编辑器中使用 ⌘/Ctrl + 单击打开链接；列表预览可直接单击。Markdown 图片采用相对路径；无相对路径前缀的引用和 Wikilink 由库内解析器定位。

## 同步与并发

同步继续由外部文件同步服务负责，本次未实现或接入 Obsidian Sync。Mac/iPhone 共用 iCloud Drive 仍需独立授权和双端真机验收。

保存前检查源文件 hash，外部内容变化拒绝覆盖；不完整扫描时保留草稿。Swift 使用系统文件协调，浏览器使用暂存写流并在 close 前再次校验。浏览器不能与外部程序进行系统级原子比较交换，最后检查与提交之间仍有竞态窗口，因此本次不宣称能可靠合并同时编辑。

## 多级标签导航

侧栏按标签而非物理目录组织内容。`工作/项目/设计` 自动生成“工作 → 项目 → 设计”，支持逐级展开和收起；父标签筛选包含所有后代。计数按笔记去重：一篇笔记同时有多个子标签，父级只计一次。父级只作为索引分类生成，不写回原文。实际目录和附件路径保留，继续兼容 Obsidian；编辑现有笔记仍保存到原路径，新建笔记沿用库的默认保存位置，并继承当前选中的标签。
