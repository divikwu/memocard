## 交互和实现

- 涉及历史草稿时，横幅改为“发现 N 条待确认草稿”；弹窗为“查看保留草稿”；记录标记为“历史草稿 · 待确认所属笔记库”。说明其与有无标签无关，不能仅凭历史草稿提示判断最近保存失败。
- “稍后处理”明确只关闭本次提醒。
- 每条历史草稿提供“保留草稿，不再提醒”。只有用户明确选择后才保存提醒设置，不把不同内容自动判为“已保存”。这些草稿仍可从列表的“查看保留草稿”入口恢复。
- Native core / 经授权的本机 Web 使用 `dismissDraftReminder`，独立写入本机 `draft-reminders/<localScope>.json`。不修改草稿 JSON 或 Markdown。设置按当前目录实例、草稿来源和完整文件指纹隔离，不随复制库传播。
- 过期版本请求被拒绝；草稿字节变化会重新提醒。设置损坏或写入失败时保持提醒和恢复入口。提醒设置不等待完整索引，也不执行源文件事务恢复。
- 只有后端声明相应 capability 才显示持久化提醒按钮；独立浏览器文件夹后端本轮没有扩展此 API。
