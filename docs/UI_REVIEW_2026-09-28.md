# MemoCard 全 UI 审查 · 2026-09-28

原审查结论：导航骨架已统一，但业务页面和状态尚未达到整体验收标准。

**22:40 整改更新：下列 10 项已完成本轮整改与回归；原始发现和截图保留供比较。** 验证覆盖桌面浏览器、Mac App 与 390px 响应式页面；iPhone 本轮仅编译验证，未做真机输入或跨设备同步验收。

## 范围与证据

本轮新截图、界面交互及当前源码联合审查。独立 Web 5179：未连接、设置、菜单、主题、390×844 响应式；已授权 Chrome 本机 Web 55715：目录、笔记、草稿、新建编辑器。原生窗口仍载有旧页面，因此不将其旧页面缺陷归因于最新源码。截图保留原始比例，不以系统大屏截图中的绝对字体大小比较不同平台。

## 优先修复

1. **P1 目录上下文与新建保存位置不一致。** 截图03/05；App.tsx newNote 固定 notes/<id>.md，编辑器无位置显示。在子目录新建后笔记会消失于当前筛选。应默认保存所选目录，或在实现前明确告知保存根目录。
2. **P2 未连接、空列表和正常列表使用两套表面样式。** 截图01/04/07；未连接、EmptyState和LoadingNotes仍用带边框阴影的Card，正常列表使用无边框灰底。统一状态组件；未连接不显示禁用搜索。
3. **P2 草稿列表显示源语法和图片路径。** 截图04，App.tsx草稿body直接放入p；改为安全预览或清理后的纯文本摘要，保留附件数量提示。
4. **P2 长笔记无提示截断。** 截图07所示列表入口结合源码 max-h-[360px] overflow-hidden，超出时没有展开/阅读全文入口；此条裁切条件由源码确认，本轮未写入长笔记重现。增加明确阅读全文行为，分离阅读与编辑。
5. **P2 标签筛选范围因入口不同而变化。** App.tsx：侧栏标签经navigate清除folder，卡片标签仅setTag保留folder；同名标签得到不同结果。应统一全库或当前目录口径，并显示可清除的范围。此条为代码发现，未另造数据交互重现。
6. **P2 独立Web与Mac本机Web缺少醒目的模式识别。** 截图01与03主体同构，只有设置说明区分。应在库菜单显示“直接访问文件夹”或“通过Mac App连接”；连接错误必须提供与实际模式一致的恢复方式。本轮未人为中断连接。
7. **P2 移动触控规格不统一。** 截图08与DOM测量：顶部44px，设置控件36px、重置32px；FolderBranch折叠按钮源码固定32px。统一项目44px目标；这不是已确认WCAG AA失败。
8. **P3 未连接菜单存在虚拟库条目。** 截图10，隐藏未连接的当前库可点击行，用明确未连接状态替代。
9. **P3 图标语义和文字不统一。** 截图03/04/05，内部编辑使用外链箭头；“新建笔记/记一条”等名称不一致。emoji由标签名哈希自动分配，与含义无保证，改名会变，宜保留emoji但支持显式选择或统一默认。
10. **P3 页面标题规则不一致。** 所有笔记隐藏内容标题，草稿/设置重复顶栏标题；目录额外显示notes技术路径。应固定页面标题、筛选状态与辅助文案的层级，避免逐页堆叠。
