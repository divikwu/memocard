## 已修复

1. **标题更新中断自动保存和焦点。** App 将标题同步到父组件后，新的 `initial` 对象会重新执行 Editor 的初始化 effect。清理过程取消自动保存定时器，初始化又将焦点移向正文。现在会话以首次打开的 Draft 初始化，同一笔记的标题更新不重启会话；切换笔记仍由现有 `key={editing.id}` 创建新会话。
2. **取消拖动丢失原选区。** 握柄拖动开始时记录原编辑状态，Esc、拖动结束、窗口失焦或页面隐藏时清理预览与滚动，并在文档未改变时恢复原选区。拖动期间文档若已改变，不恢复过期选区；成功移动后保留移动结果。
3. **组合输入期间插入按钮改变光标。** 块插入按钮与拖动取消快捷键补充组合输入检查，避免触发结构操作或改变选区。
